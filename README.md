# NeonCalc

A native Android calculator with a cyberpunk-inspired neon interface, built with Kotlin and Jetpack Compose.

## Open and run

1. Open this repository in the latest Android Studio.
2. Let Gradle sync and install the Android SDK platform 35 if prompted.
3. Run the `app` configuration on an emulator or Android device (Android 7.0 / API 24 or newer).

The calculator supports addition, subtraction, multiplication, division, parentheses, decimals, sign toggle, percent, clear, and backspace.
